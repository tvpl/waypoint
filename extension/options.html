Salvar no Waypoint

Conecte a extensão ao seu Waypoint para salvar páginas e links com um clique.

O mesmo endereço que você abre no navegador. A extensão pede permissão para acessar apenas este site.

No Waypoint, abra Configurações → Tokens de API, crie um token e cole aqui. Ele fica guardado só neste navegador.

Atalhos

  • CtrlShiftS abre o Salvar no Waypoint na aba atual
  • AltShiftS salva direto, na última coleção usada
  • Botão direito em um link ou página → Salvar link no Waypoint

Para mudar os atalhos, use chrome://extensions/shortcuts.
